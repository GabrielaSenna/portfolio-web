Projeto 00 IA aplicada · Allora Company

Allora Social Analytics

O time de social media da Allora precisava otimizar seu relatório de desempenho. Construí um dashboard que se conecta à API da Meta e, com agentes de IA sobre o Claude, classifica os temas dos posts, identifica os que mais engajaram e os assuntos em alta, acompanha a evolução de seguidores, analisa concorrentes e redige o relatório com recomendações de ação. Pronto, com 7 contas conectadas e login gerenciado pelo Cloudflare. Limite encontrado: as primeiras recomendações saíam genéricas; calibrei a IA junto com o time de social media até ficarem assertivas.

  • Claude API
  • Agentes de IA
  • API da Meta
  • Cloudflare Workers
